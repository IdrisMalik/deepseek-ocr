# Asset provenance and reuse

All fixtures are purpose-generated or purpose-corrupted for OCR testing. They contain no copied documents, web images, personal data, or third-party photographs. Image contents, document contents, reference text, and recordings are released with this suite for reuse in OCR testing.

## Images

- **T01-T15, T19, T26-T28** were generated by Pillow from text literals and geometric shapes. T01-T15 use `tools/generate_fixtures.py`, the bundled fonts, and the Pillow version pinned in `requirements.txt`; they are byte-reproducible on the verified Windows/Python 3.13/Pillow 13.0.0 environment. T19 and T26-T28 came from the 2026-11-18 corpus generator (`tools/provenance/generate_corpus.py`) using Windows system fonts (Arial and Consolas) and are frozen by SHA-256.
- **T29** is a deliberately corrupt PNG: a valid PNG signature followed by invalid bytes, written by the same corpus generator.
- T13 is a two-frame TIFF and T14 is a three-frame animated GIF. Both are synthetic.

T01-T15 were regenerated during the 2026-11-18 suite rework. The recordings for those fixtures predate the regeneration and came from a different Pillow/FreeType build that is not reproducible in the current environment. Reference text and layout are unchanged, but byte identity with the original uploads is not guaranteed.

## Documents

T16-T18 and T23-T25 are PDFs generated with ReportLab. T20 and T22 are DOCX files generated with python-docx; T22 embeds a Pillow-drawn chart. T21 is a PPTX generated with python-pptx. They use ReportLab or Office libraries and, for some fixtures, Windows system fonts. Regeneration is not byte-identical. The exact files are pinned by SHA-256 and their generators are preserved under `tools/provenance/` for provenance.

The generators in `tools/provenance/` write beside themselves. They document how the frozen files were produced, not a one-command rebuild, and regeneration is not byte-identical.

## Recordings

`recordings/live-2026-11-18/` contains responses from authorized DeepSeek OCR API calls made on 18 November 2026. Derived fields such as payloads and cleaned text were removed; pages, envelope metadata, usage, latency, and errors were retained. The recordings contain no credentials. They are provider output, not authored reference text.

## Fonts

The bundled font files are included solely to make T01-T15 generation reproducible:

- DejaVu Sans Regular and Bold from [DejaVu Fonts](https://dejavu-fonts.github.io/), under the Bitstream Vera license with DejaVu changes in the public domain. The applicable notice is in `DejaVu-copyright.txt`.
- Noto Sans Devanagari and Noto Sans CJK from [Google Noto Fonts](https://github.com/notofonts/noto-fonts) and [Noto CJK](https://github.com/notofonts/noto-cjk), under SIL Open Font License 1.1. Applicable notices are in `Noto-Core-copyright.txt` and `Noto-CJK-copyright.txt`.

The font notices are included in full. Generated raster images and documents are not themselves font software and may be reused as test fixtures.
